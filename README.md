# 한일고 매니저

문명의 확장과 풋볼 매니저의 육성을 섞은 학교 정복 게임의 웹 프로토타입입니다.
신임 교사가 되어 공주 한일고를 장악하고, 이어서 전국 명문고를 정복합니다.

## 지금 되는 것

- 시작 화면: 로딩 후 대기 화면(이어서 플레이·새로 플레이·세이브 파일·설정). 저장된 게임이 없으면 이어서 플레이는 숨김
- 새로 플레이: 이름 → 담당 과목(10개, 과목마다 교사 능력치 +2) → 칭호와 저장 칸 선택
- 칭호: 플레이 중 조건을 채우면 얻고, 프로필(위쪽 이름)에서 골라 이름 앞에 붙임
- 세이브 파일: 저장 칸 3개, 불러오기·삭제·내보내기·가져오기 / 설정: 테마, 글자 크기
- 캠퍼스 지도: 번호 없는 일러스트에서 건물 14곳(골프장 포함)을 누르면 그 건물의 1층 평면도로 이동, 마우스를 대면 이름 표시
- 평면도: 층 전환, 타일을 누르면 종류·특징·이어진 곳 표시
- 평면도 데이터가 있는 건물: 현제관 C동 (나머지는 "준비 중")
- 담임반: 1학년 30명 생성 (스탯 26개, 성격, 성향, 포텐, 행운, 사기, 욕구, 결속도). 숨은 원석·리더 후보·문제아가 1명씩 반드시 포함
- 학생 상세: 능력치, 성격의 성장 방향과 훈화 반응, 성향 효과, 욕구, 학생 관찰(입학식 주간 무료 3회)
- 현제관 C동 호실에 담임반 학생이 4명씩 배정되고, 평면도에서 호실을 누르면 사는 학생이 보임
- 턴 진행: 위쪽 게임 바(주차·AP·피로·예산·신임)와 **다음 주로** 버튼
- 행동·훈련: 훈련 배분(지적·신체·휴식), 학급 훈화, 야식, 반 단합 행사, 상담, 관찰, 특훈, 교장 보고, 교사 연수, 야근
- 주말 정산: 능력치 성장, 욕구 증가, 일탈(성공은 조용히, 발각만 편지함으로), 사기 변화, 랜덤 생물, 금요일 귀성, 주간 보고
- 받은 편지함: 주간 보고와 소식, 일탈 발각 시 감싼다·벌점·크게 혼낸다 선택
- 진행 상황은 이 브라우저(localStorage)의 저장 칸에 매주 자동 저장됨

## 실행

브라우저가 `file://`에서는 JSON을 불러오지 못하므로 로컬 서버로 엽니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다. GitHub Pages에 올리면 별도 설정 없이 동작합니다.

## 구조

| 경로 | 내용 |
| --- | --- |
| `index.html` | 진입점 |
| `css/style.css` | 화면 스타일 (라이트·다크 테마) |
| `js/main.js` | 화면 전환 (게임 밖: `#title`, `#new`, `#saves`, `#settings` / 게임 안: `#campus`, `#b-<건물 id>`, `#class`, `#s-<학생 id>`, `#inbox`, `#plan`, `#profile`) |
| `js/menu.js` | 로딩, 대기 화면, 새로 플레이, 세이브 파일, 설정 화면 |
| `js/profile.js` | 교사 프로필과 칭호 선택 |
| `js/settings.js` | 설정 저장과 적용 |
| `js/campus.js` | 캠퍼스 지도와 건물 영역 |
| `js/building.js` | 층별 평면도 |
| `js/homeroom.js` | 담임반 목록 |
| `js/student.js` | 학생 상세 |
| `js/inbox.js` | 받은 편지함 |
| `js/plan.js` | 행동·훈련 |
| `js/chrome.js` | 위쪽 게임 바와 알림 |
| `js/ui.js` | 화면 공통 조각 (별점, 사기, 욕구 막대 등) |
| `js/game/` | 게임 로직: 난수(`rng.js`), 학생 생성(`students.js`), 저장(`state.js`), 턴 진행(`turn.js`), 달력(`calendar.js`) |
| `js/content/` | 룰북 데이터: 스탯, 성격 23종, 성향 16종, 이름, 교과목(`subjects.js`), 칭호(`titles.js`) |
| `data/campus.json` | 건물 목록과 지도 위 영역 좌표 |
| `data/floorplans/*.json` | 건물별 평면도 타일 (좌표, 종류, 인접 정보) |
| `assets/campus.webp` | 캠퍼스 일러스트 |

## 평면도 추가하기

1. `data/floorplans/`에 `hyeonjegwan-c.json`과 같은 형식으로 파일을 만듭니다.
2. `data/campus.json`의 해당 건물에 `"floorplan": "data/floorplans/<파일 이름>"`을 추가합니다.

타일은 통로(복도·계단·입구)를 통해서만 서로 이어집니다 (룰북 8.1절 인접 규칙).
